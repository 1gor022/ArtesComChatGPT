# Método PRODUTO

Landing page pronta para GitHub e Netlify.

## Publicar na Netlify

1. Envie todos os arquivos desta pasta para um repositório no GitHub.
2. Na Netlify, escolha **Add new site** e depois **Import an existing project**.
3. Conecte o repositório do GitHub.
4. A Netlify usará automaticamente as configurações do arquivo `netlify.toml`.

## Rodar no computador

```bash
npm install
npm run dev
```
